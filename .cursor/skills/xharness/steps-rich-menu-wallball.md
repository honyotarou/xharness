# 親 0 の続き — CLI 表層の壁打ち（LINE のリッチ枝スロット）

メインの **親 0** の一部として任意で使う。**サブコマンド階層・help テキスト・エラーメッセージ**を揃えたいときの壁打ち用。

## 使いどころ

- 新規サブコマンドやオプションの**名前・説明文・例**を決める。
- **同じ種類の失敗**（例: パス不正、デバイス未接続）でメッセージのトーンを揃える。
- **終了コード**をどの `ExitCode` にマップするかの合意。

## エージェントの進め方

1. 既存の近いコマンドの help / 例外メッセージを **Read** してトーンを合わせる。
2. 案を **表**（コマンド / ユーザーが見る文 / ExitCode）で出す。
3. 合意後、**実装 + テスト**（help のスナップショットや例外メッセージのアサーションがあればそれに合わせる）。
